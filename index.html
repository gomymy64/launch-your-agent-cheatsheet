8 шагов до живого агента

01

Установи скилл

Копируешь ссылку на репозиторий и просишь Клода установить - он сам всё сделает.

Открой Claude Code (десктоп)
Вставь промпт со ссылкой на репо
💬 Промпт 1 - установка
Установи этот скилл глобально https://github.com/anthropics/launch-your-agent
💡 Если скилл уже стоит - Клод сверит с актуальной версией на GitHub и обновит. Бонусом установится второй скилл wrap-up - красиво завершает проект: поздравляет, собирает обзорную страницу и предлагает 1-2 улучшения для агента.
02

Перезапусти приложение и запусти скилл

Чтобы новый скилл подхватился, Claude Code надо перезапустить.

Полностью закрой Claude Code и открой заново
Введи / и начни печатать launch - увидишь скилл в списке
Запусти без дополнительного текста - он сам проведёт интервью
💬 Промпт 2 - запуск
/launch-your-agent

Давай общаться на русском
03

Расскажи, какого агента хочешь

Скилл покажет примеры (радар-дайджест по расписанию, аналитик-ресёрчер, воркер внутри продукта) и спросит, что тебе нужно. Отвечаешь своими словами.

💬 Промпт 3 - задача агента (пример из видео)
Сегодня хочу оставить пример простым, не задействуй кучу сторонних ключей. Думаю, вариант первый - ежедневный дайджест новостей - самый полезный: поиск интересных тем и трендов в моей нише, с подачей в виде зацепки, релевантной моей аудитории. Имеет ли это смысл?
💡 Спрашивай у Клода «имеет ли это смысл?» или проси задать вопросы тебе - у тебя могут быть слепые зоны, а он разложит по полочкам.
💡 Попроси задавать вопросы табличкой с вариантами - чтобы тыкать, а не печатать.
04

Ответь на интервью

Скилл задаёт конкретные вопросы. Ответы из видео:

Что в дайджест → громкие релизы и тулсы
Откуда тянуть → любые AI-новости из сети
Формат выхода → зацепка под каждую тему
Сколько тем → топ-5
05

Главный промпт - система, что не жрёт токены

⚠️ Без этого промпта прогон может съесть ~$4

Встроенный грейдер гоняет работу агента до 3 раз, пока не сойдётся - вот эта штука и ест токены. С этим промптом - центы за прогон.

💬 Промпт 4 - экономия токенов
Самое главное сделай систему которая не жрет много токенов без лишней проверки итераций грейдеров. Чтобы не сожрало сильно. По результату хочу комбинацию - историю со ссылкой, цепляющую подачу, и почему это важно для моей аудитории. Насчёт ниши - ты её и так хорошо понимаешь. По источникам - давай начнём с поиска по интернету. Модель возьмем Sonnet 4.6
⚙️ Модель - Sonnet 4.6 (не Opus - он ест сильно больше токенов). Если скилл предложит грейдеры и доп-проверки - откажись, для простого дайджеста не нужны.
06

Вставь API-ключ

Зайди на platform.claude.com → раздел API keys → создать ключ → назови → скопируй
Ключ вставляется НЕ в чат, а в системный файл my-agent/.env
Чтобы не искать файл руками - попроси Клода дать путь
💬 Промпт 5 - путь для ключа
Я хочу вставить ключ, дай мне путь к этому файлу, к директории на моем ПК, я вставлю напрямую
07

Одобри план и наблюдай

Клод покажет структуру агента: модель, промпт, разрешения, инструменты, расписание. Одобряешь - и он разворачивает агента в твоём кабинете.

Смотри живой прогон: platform.claude.com → твой агент → вкладка Sessions - там логи: что сканирует, какие вызовы делает, как сам себя исправляет
Скилл соберёт локальный дашборд (HTML-файл на твоём ПК) - открывай в браузере в любой момент: статус агента, оценки результатов, план развития
08

Забери результат

Когда прогон завершится - попроси показать дайджест
По умолчанию агент отдаёт Markdown - попроси в HTML, красивее смотреть
💬 Промпт 6 - результат
Дай мне сам дайджест, что было сделано. Сделай его в HTML
💡 Агент теперь живёт в облаке: поставь на расписание - каждое утро сам соберёт свежак. Хочешь прокачаться в Claude Code - заходи в Sessions и читай логи, так поймёшь, как он думает.
